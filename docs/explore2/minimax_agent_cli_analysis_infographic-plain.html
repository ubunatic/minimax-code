1. Architectural Divergence: How mcode Operates

Unlike conventional coding harnesses that treat context management as conversational prompting, MiniMax Code handles agent steering through deterministic, code-enforced boundaries in its TypeScript monorepo core.

notMetStreak <= 5
🧸 Context Bisection & Floor

Compaction triggers strictly evaluate exact tokenizer counts including MCP tool schema footprints. Historical context is bisection-cut using safeCutForIndex to ensure tool-call pairs are never orphaned, avoiding provider schema crashes.

🛡 Two-Tier Security Architecture

Exploration subagents have tool schemas (write, edit, task) omitted entirely from declarations. Dynamic AST checkers unwrap shell calls to evaluate structural intent before global permissions bypass can execute.

⚠ Tri-Breaker Circuitry

Monitors non-convergent behavior via three breakers: SHA-256 missing-item fingerprint hashes (notMetStreak), worker response content hashing for inaction, and mandatory 5-turn terminal audits persisted in SQLite CAS epochs.

2. Empirical SWE Performance & Benchmark Attribution

Evaluation of foundational neural weights against benchmark suites. Crucially, empirical records show benchmark scores are attributed to model weights rather than client scaffolding.

SWE-bench Resolve Rates (%)

Verified vs. Pro (Public)

MiniMax M3 demonstrates frontier-grade performance on SWE-bench Pro (59.0%), placing on par with OpenAI GPT-5.5 (58.6%) and ahead of Claude Opus 4.8 (48.9% avg).

Terminal-Bench 2.1 Success Rate (%)

Terminus 2 Scaffolding

On Terminal-Bench 2.1 (evaluated using Terminus 2 harness), MiniMax M3 achieves 66.0%, trailing GPT-5.5 in Codex CLI (82.7%) and Claude Opus (84.1%).

⚠

Critical Attribution Finding: Scaffolding vs. Neural Weights

Official evaluation disclosures document that MiniMax benchmark achievements on SWE-bench Verified and Pro were established using external scaffolding (Claude Code, Droid, or Mini-SWE-Agent) with overridden prompts, and Terminal-Bench tests used Terminus 2. The standalone mcode CLI provides system stability, fault tolerance, and unbypassable permission security, rather than driving benchmark uplift.
